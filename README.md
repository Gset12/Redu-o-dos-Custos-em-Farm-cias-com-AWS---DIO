- Data: 28/04/2026

- Responsável: Guilherme

## Introdução
Este relatório apresenta o processo de implementação de ferramentas na empresa Abstergo Industries, realizado por Guilherme. O objetivo do projeto foi elencar 3 serviços AWS, com a finalidade de realizar diminuição de custos imediatos.

## Descrição do Projeto
O projeto de implementação de ferramentas foi dividido em 3 etapas, cada uma com seus objetivos específicos. A seguir, serão descritas as etapas do projeto:

Etapa 1: 
- Amazon RDS
- Otimização e gerenciamento de bancos de dados relacionais
- A empresa possuía bancos de dados locais com altos custos de manutenção e baixa escalabilidade. A migração para o Amazon RDS permite a utilização de instâncias gerenciadas, com backup automático, escalabilidade sob demanda e pagamento conforme uso.

Etapa 2: 
- Amazon VPC
- timização de rede e isolamento de infraestrutura
- Foi implementada uma VPC para segmentar os recursos da empresa em sub-redes públicas e privadas. Isso permitiu maior controle do tráfego, redução de exposição a riscos e diminuição de custos com soluções externas de segurança e redes físicas.

Etapa 3: 
- Amazon S3
- Armazenamento de dados e redução de custos com banco de dados
- Parte dos dados que estavam em bancos relacionais foi migrada para o Amazon S3, especialmente arquivos, logs e dados históricos. Com o uso de políticas de ciclo de vida e classes de armazenamento, foi possível reduzir significativamente os custos de armazenamento, mantendo alta durabilidade e disponibilidade.



## Conclusão
A implementação de ferramentas na empresa *Abstergo Industries tem como esperado a redução de custos*, o que aumentará a eficiência e a produtividade da empresa. Recomenda-se a continuidade da utilização das ferramentas implementadas e a busca por novas tecnologias que possam melhorar ainda mais os processos da empresa.
